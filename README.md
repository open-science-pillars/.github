# .github

Org-wide community files for Open Science Pillars: the
[profile README](profile/README.md), five issue templates (bug, feature,
new skill, new domain capability, new knowledge concept), the pull request
template with the DCO and review checklist, [GOVERNANCE.md](GOVERNANCE.md)
(lazy consensus, federated repository authority, the owning teams and the
review rules), the Contributor Covenant v2.1
([CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)) and [SECURITY.md](SECURITY.md).
Each repository declares its maintainers and roadmap policy in
`.osp/governance.yaml`.

The canonical documentation (the specification, the glossary, the
contributor guides and the decision records) lives in the marketplace
repository; start at its
[documentation map](https://github.com/open-science-pillars/marketplace/blob/main/docs/README.md).
